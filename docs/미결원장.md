# 미결원장 — 프론트엔드

> 프론트 미결의 정본이다(`CLAUDE.md` 11장).

## 규칙

- 번호는 `FE-n` 이다(1부터 차례로 · 닫힌 번호를 다시 쓰지 않는다).
- 🔴 **수(집계)를 적지 않는다.** "열린 것 몇 건" 같은 합계를 이 문서에 두지 않는다. 필요하면 표를 세어 확인한다.
- 🔴 **백엔드 미결은 백엔드 원장이 정본이다**(백엔드 저장소 `docs/미결원장.md`). 여기서는 번호(예: `A3-51`)로 가리키기만 하고 내용을 옮겨 적지 않는다.
